# 나만의 블로그 틀

옵시디언에서 쓴 md 글을 올리면, 최신 글이 맨 위에 오는 블로그가 자동으로 만들어집니다.

## 내가 만지는 곳 (꼭 두 군데 + 선택 두 군데)

| 무엇 | 어디 | 하는 일 |
|---|---|---|
| 블로그 이름·소개 | `settings.md` | 위 세 줄만 바꾸기 |
| 글 | `posts` 폴더 | md 글 파일을 올리기 |
| 디자인(선택) | `style.css` | 색·글꼴 바꾸기. 글 내용과 상관없음 |
| 내 그림(선택) | `images` 폴더 | 글에서 `![설명](images/그림.png)`로 넣기 |

나머지 파일(`build.js`, `vercel.json`, `package.json`)은 **건드리지 않습니다.**

## 미리보기와 한 파일 블로그

- `node build.js` → `public/index.html`을 더블클릭하면 올리기 전에 내 PC에서 미리 볼 수 있습니다.
- `node build.js --single` → `blog-single.html` 한 파일이 생깁니다. 디자인과 내 그림(base64)이 파일 안에 다 들어 있어서 카톡·메일로 보내도 그대로 열립니다.

## 글 맨 위에 적는 머리말

```
---
title: 글 제목
date: 2026-10-19
tags: [AI, 뉴스]
summary: 목록에 보일 한 줄 소개
source: 원문 주소(있으면)
---
```

- `date`가 최신일수록 목록 맨 위로 갑니다. 옵시디언 웹 클리퍼가 적어 주는 `created` 날짜도 읽습니다.
- 날짜가 없으면 맨 아래로 갑니다.
- `draft: true`를 넣으면 블로그에 안 보입니다(숨김).

## 올리면 무슨 일이 생기나

깃허브 `posts` 폴더에 글이 들어감 → 버셀이 알아차림 → 1분 안에 블로그가 다시 만들어짐 → 같은 주소에서 새로고침하면 새 글이 맨 위.

## 주의

- 남의 기사 본문을 통째로 올리지 말고, 요약·내 생각·출처 링크만 올립니다.
- 개인정보(전화번호, 주소 등)는 올리지 않습니다.
